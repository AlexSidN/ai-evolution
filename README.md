# Ai Evolution

Учебная папка Алексея для тех, кто осваивает работу с ИИ и Claude Code.
Программистом быть не нужно.

Здесь нет готовых настроек, которые надо скачать и поставить. Здесь уроки:
с чем стоит разобраться, чтобы ваш Claude работал точнее, и запросы,
с которыми вы разбираетесь в этом сами, в своём Claude.

## Как начать

1. Откройте Claude Code.
2. Попросите его: «Скачай себе эту папку с GitHub и открой её» — и дайте
   ссылку на эту страницу.
3. Когда папка откроется, напишите «привет». Дальше Claude всё объяснит сам.

## Что внутри

- `lessons/` — уроки.
- `CLAUDE.md` и `WELCOME.md` — памятки для Claude: как вести с вами разговор.
- `radar/` и `BACKLOG.md` — рабочие материалы автора, читать их не обязательно.

Проект в начале пути, уроков пока мало. Чтобы получить новые, скажите Claude
в этой папке: «обнови уроки».
